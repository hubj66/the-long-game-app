# The Long Game

> **Early test release.** The app is in private development and not ready for
> family use yet. Install it only to try it out, with pretend money.

A mastery-based investing education app for families. Children learn in short
lessons, then practise with pretend money in a yearly investing cycle that a
parent sets up.

It needs a PostgreSQL database. Open the **Documentation** tab for the
installation steps.
