# The Long Game - Home Assistant app repository

> **Early test release.** The Long Game is in private development and not ready
> for family use yet.

Add this repository in Home Assistant under
**Settings > Apps > App store > menu > Repositories**, then install
**The Long Game**.

This repository is generated for each release. The source code, the
installation guide and the changelog live at
<https://github.com/hubj66/the-long-game>.
